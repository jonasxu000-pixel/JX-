## 2. 简介文案

### 50 字内简介

一款支持好友实时联机、同屏双人和本地人机对战的15路五子棋小游戏。

### 完整介绍

棋遇五子棋是一款轻量、简洁的 15 路五子棋微信小游戏。玩家可以创建六位好友房并通过微信邀请好友实时对局，也可以在单台手机上进行人机对战或同屏双人对战。游戏支持黑棋先行、实时落子、胜负与和棋判定、投降、双方确认再战、离开处理，以及头像昵称展示。

## 3. V1.0.0 版本说明

首次发布：支持好友房创建、分享与加入，双方实时落子和胜负同步；支持投降、退出、双方确认再战和前后台恢复；提供本地人机对战与同屏双人对战；完成玩家头像昵称、隐私授权和多机型竖屏适配。

## 4. 审核员操作说明

本版本不需要测试账号，审核员可使用当前微信身份直接体验。

1. 进入首页后，可直接点击“人机对战”完成单设备棋局验证。
2. 点击“同屏双人对战”，可在一台设备上交替落子并验证胜负判定。
3. 点击“创建好友房”，创建成功后会自动进入等待页；可复制六位房间号或点击“邀请微信好友”。
4. 第二个微信账号从分享卡片进入，或在“加入好友房”输入六位房间号，即可开始实时对局。
5. 好友对局中可验证交替落子、投降、退出，以及双方都确认后开始新一局。
6. 点击首页玩家资料卡，可主动同步微信头像昵称、选择本地头像或修改游戏昵称。

补充说明：好友联机完整验证需要两个微信账号；单账号仍可通过人机对战和同屏双人对战验证核心规则与结算流程。

## C. 当前待实机（未勾选，附复测路径）

### C1 计时

- [ ] 好友房默认每步 30 秒；在设置改为 60 / 120 秒或不限时后重新开新局验证生效
- [ ] 换手计时：当前方落子后切换为对手计时，超时方判负，双方文案正确
- [ ] 切后台后返回：剩余时间按绝对截止时间扣减，未超时则继续，已超时则正确判负

### C2 悔棋（两个范围与次数）

- [ ] 额度 1 次（默认）与改为 2 / 3 次后，剩余次数显示与实际可用一致
- [ ] "上一手"：必须在申请者自己刚落子后申请，撤回申请者自己刚落下的一手
- [ ] "上一轮"：必须在自己回合申请，撤回双方最近两手
- [ ] 对手 15 秒不响应视为拒绝；拒绝或取消都计次数；撤回不补时
- [ ] 确认期间锁盘，重复点击不产生二次请求；对局结束后不可悔棋

### C3 先手换色

- [ ] 好友首局随机黑白，双方看到的棋色与落子一致
- [ ] 再战默认负方执黑、平局交换；若开启每局轮换则按配置轮换
- [ ] 换色后玩家标识、落子、结算、等待页与恢复记录一致

### C4 好友房全流程（建房 / 加入 / 分享 / 退出 / 恢复）

- [ ] 建房 → 自动进入等待页 → 复制房间号可粘贴到微信聊天框
- [ ] 分享卡片可发送；好友点击后房间号自动带入（冷启动与热启动各一次）
- [ ] 另一台手机加入成功，房主约 1.2 秒内自动进入对局且只跳转一次
- [ ] 等待页 / 对局页正常退出；断网退出提示失败，恢复网络后可重试
- [ ] 重复退出只请求一次；退出时切后台再恢复不误跳转
- [ ] 加入者退出后房主回到等待页并保留原房间号

### C5 弱网与前后台

- [ ] 切换 Wi-Fi / 移动网络后可继续，或明确提示重试
- [ ] 双方分别切后台再恢复，棋盘与回合一致
- [ ] 恢复前台后旧请求不污染服务器时间、不回滚棋盘
- [ ] 慢响应时界面给出进行中/重试提示，不出现重复落子

### C6 存档恢复

- [ ] 不清理微信后台直接重开小游戏：首页、等待页、对局页均无黑屏
- [ ] 人机存档保留时限、悔棋额度与棋局进程；成长记录正确

### C7 音频、震动与小屏

- [ ] 背景音乐与落子震动反馈在真机正常
- [ ] 320×568 矮屏下规则说明可被发现，展开/折叠按钮不与底部手势区重叠
- [ ] 矮屏等待页摘要完整可读，长昵称不遮挡关闭按钮

### C8 账号与资料

- [ ] 微信登录弹窗、微信头像昵称、相册头像与自定义昵称真机通过
- [ ] 8～12 字昵称在好友对局顶部完整可辨识

### C9 人机与残局

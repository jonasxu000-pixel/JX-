# RC19 可选规则与再战棋色

## 默认与选项

好友房、同屏新局默认 **每步 30 秒、每方每局 1 次悔棋申请、无禁手**。规则页可一键恢复；加入的好友沿用房主创建时的设置。设置在本机记忆，开局后不能改规则。

| 设置 | 选项 / 行为 |
| --- | --- |
| 每步用时 | 不限时、30、60、120 秒；超时判负，切后台不暂停 |
| 悔棋申请次数 | 不允许、每方 1、2、3 次；拒绝、取消或未回应也消耗次数 |
| 悔棋范围（高级设置） | 默认上一手：自己刚落子后申请；上一轮：轮到自己时退回双方最近两手 |
| 悔棋确认 | 须对手同意，最多等待 15 秒；等待计时，撤回不补时，已结束对局不可悔棋 |
| 棋形规则（高级设置） | 无禁手、恰好五子、连珠禁手 |
| 首手天元（高级设置） | 默认关闭；开启后黑棋第一手须落在中心，其他落点提示并保留棋盘与计时 |
| 好友先手（高级设置） | 首局随机分配黑白；默认再战负方执黑，平局交换；可切换为每局交换 |

人机新局也改为默认 30 秒、一次悔棋；可选次数，始终撤回自己上一手与 AI 回应，AI 尚未应手也能撤回。AI 使用自由规则，思考时间不占玩家时限。残局仍不限时。

同屏没有账号身份，显示黑白双方；好友棋色按房主/访客身份独立维护。双方确认再战时，棋色、回合、棋盘、计时和悔棋额度在同一云事务更新，重进房间仍使用该局真实棋色。

## 连珠裁判范围与依据

采用 [国际连珠联盟规则第 3、9 条](https://www.renju.net/rifrules/) 的棋形与胜负定义：黑棋三三、四四、长连判负，白棋五子及以上获胜；黑棋同时形成恰好五子时优先获胜。“三”必须能合法形成两端均可恰好连五的直四；延伸自身构成禁手的假活三不计为三，递归校验。双四也检查同一方向的不同四，直四两个胜点不重复计成两个四。可参考联盟的 [禁手与假活三说明](https://www.renju.net/advanced/)。

这是适合好友约定的 **连珠禁手模式**，不包含赛事交换开局、指定前三手与第五手候选等完整职业开局程序。首手天元可独立约定，默认关闭。恰好五子模式对双方都要求恰好五子，长连继续对局，不属于连珠禁手。

## 兼容与维护

- 规则协议升级到 v2。旧默认规则升级为 30 秒 / 一次 / 无禁手，修习值、关卡星级、历史、音效及难度偏好保留；已开始的旧人机存档、v0/v1 好友房保持原规则。
- 新客户端能加入旧房；旧客户端不能加入 v2 房间，避免棋色或裁判不一致。建房前检查 `advancedRuleVersion:2`；服务端同时保留 `ruleVersion:1` 供旧客户端使用。
- `utils/gomokuRules.js` 是纯函数裁判的维护源；部署前同步至 `cloudfunctions/roomAction/gomokuRules.js`。回归门禁检查两者逐字一致。客户端处理同屏判定和天元提示；好友胜负由云端裁判。
- 本轮没有新增云集合、权限、发布端依赖或美术素材。禁手只在相应模式计算，现有每秒计时和后台取消机制继续使用。

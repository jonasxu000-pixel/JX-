# Changelog

## V1.0 RC3 - 2026-07-28

### 主干修复

* “再来一局”改为双方确认，单方点击只显示已准备
* 任一玩家退出后清除再战确认并立即阻止继续落子
* 退出、再战确认和落子统一接受服务端事务状态校验
* 双方同时确认再战时只会执行一次棋盘重置

### 玩家资料

* 首页新增微信快捷登录和已登录头像昵称
* 使用微信原生用户信息按钮，玩家主动授权后才读取头像昵称
* 新增玩家资料页
* 支持微信头像昵称、相册自选头像、系统默认头像和自定义昵称
* 相册头像保存到小游戏本地文件沙箱
* 拒绝资料授权仍可使用默认资料继续游戏

## V1.0 RC2 - 2026-07-28

### UI 与好友体验

* 建立暖玉、墨绿、棋盘金的统一 Canvas 视觉体系
* 统一首页、建房、等待、加入、对局和胜负结算的卡片与按钮层级
* 优化全套中文文案，明确好友房、棋色、先后手和操作反馈
* 加入页移除手动粘贴按钮，进入页面自动识别剪贴板中的六位房间号
* 空房间号格改为真正留空，避免被误解为已有隐藏数字
* 创建页、等待页新增微信好友邀请
* 分享卡片携带房间号，好友点击后自动进入确认加入页
* 增加分享入口、剪贴板识别和触摸区域边界自动验证

## V1.0 RC - 2026-07-28

### 体验修复

* 启动后后台预热房间云函数，降低首次创建的冷启动概率
* 创建房间时立即显示进行状态，并对慢响应给出提示
* 创建页、等待页复制房间号后显示明确成功或失败反馈
* 加入页改为清晰六位数字格，并支持读取剪贴板房间号
* 加入者退出后，房主自动回到原房间等待页

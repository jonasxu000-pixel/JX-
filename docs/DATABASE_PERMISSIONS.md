# 云数据库权限配置

## rooms 集合权限

### 当前配置（需要修改）
- 读：所有用户可读 ✅
- 写：仅创建者可读写 ❌ **需要修改**

### 正确配置
```json
{
  "read": true,
  "write": "doc.host.openId == auth.openId || doc.guest.openId == auth.openId"
}
```

### 说明
- **read: true** - 所有人都可以查看房间信息（用于加入房间时验证）
- **write** - 仅房主或客人可以修改房间数据
  - 房主可以创建、更新、离开房间
  - 客人可以加入、更新、离开房间
  - 防止第三方恶意篡改游戏状态

## 配置步骤
1. 打开微信开发者工具
2. 点击顶部工具栏的"云开发"按钮
3. 进入"数据库"页面
4. 选择"rooms"集合
5. 点击"权限设置"标签
6. 选择"自定义安全规则"
7. 粘贴上面的 JSON 配置
8. 点击"保存"

## 验证方法
配置完成后，在控制台执行以下测试：
1. 创建房间（应该成功）
2. 加入房间（应该成功）
3. 未登录用户尝试修改（应该失败）
4. 第三方用户尝试修改他人房间（应该失败）

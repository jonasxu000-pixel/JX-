# 云数据库权限配置

## rooms 集合权限

### V1.0 正确配置
```json
{
  "read": true,
  "write": false
}
```

### 说明
- **read: true** - 所有人都可以查看房间信息（用于加入房间时验证）
- **write: false** - 客户端禁止直接写入房间数据
- 创建、加入、落子、离开全部通过 `roomAction` 云函数执行
- 云函数校验调用者身份、回合和落子规则，避免参与者绕过裁判直接篡改棋盘

## 配置步骤
1. 打开微信开发者工具
2. 点击顶部工具栏的"云开发"按钮
3. 进入"数据库"页面
4. 选择"rooms"集合
5. 点击"权限设置"标签
6. 选择"自定义安全规则"
7. 粘贴上面的 JSON 配置
8. 点击"保存"

## 验证方法
配置完成后，在控制台执行以下测试：
1. 创建房间（应该成功）
2. 加入房间（应该成功）
3. 房主或加入者从客户端直接修改房间（应该失败）
4. 未登录用户或第三方用户直接修改房间（应该失败）
5. 通过 `roomAction` 正常落子（应该成功）
